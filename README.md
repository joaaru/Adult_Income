******************************************************* Objective *******************************************************

The objective of this project is to create a machine learning prediction model using the adult income dataset to predict if the income will be <=50K or >50K for the given inputs age, education, occupation, workclass, marital-status, relationship, race, sex, native country, capital-gain and capital-loss.

******************************************************** Dataset ********************************************************

The adult income dataset also known as the “Census Income” dataset has adult records with the variables age, education, occupation, workclass, marital-status, relationship, race, sex, native country, capital-gain, capital-loss and income. This dataset is widely used for the purpose of supervised machine learning and creating the prediction model using binary classification.

**************************************************** Prediction Model ****************************************************

As part of this project, the following steps have been done for building the prediction model are:
1) Exploratory Data Analysis
2) Univariate Analysis
3) Data Cleaning
4) Bi-Variate Analysis
5) Outlier Detection and Treatment
6) Feature Engineering
7) Building the model
8) Deployment
